#  Ailyn – AI Digital Companion

---

**URL:** https://ailyn-companion-ai.lovable.app

##  Descripción

**Ailyn** es un asistente virtual impulsado por Inteligencia Artificial diseñado para brindar acompañamiento, ideas y apoyo al usuario en un entorno seguro, creativo y sin juicio.

Su enfoque combina interacción conversacional con una experiencia visual agradable, ofreciendo un espacio donde el usuario puede expresarse libremente.

---

##  Características principales

*  Chat interactivo con IA
*  Enfoque en acompañamiento emocional ligero
*  Interfaz moderna e intuitiva
*  Respuestas dinámicas y personalizadas
*  Integración con modelos de IA

---

##  Tecnologías utilizadas

*  React + TypeScript
*  TailwindCSS + shadcn/ui
*  IA (integración API)
*  Supabase
*  Playwright

---

##  Cómo ejecutar el proyecto

```bash
git clone https://github.com/Kevinpowerdash/ailyn-companion-ai
cd ailyn-companion-ai
npm install
npm run dev
```

---

##  Objetivo del proyecto

Este proyecto fue desarrollado para explorar la creación de asistentes virtuales con personalidad, combinando experiencia de usuario, diseño emocional e inteligencia artificial.
